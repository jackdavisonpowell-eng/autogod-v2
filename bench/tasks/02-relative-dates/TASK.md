# Task: relative dates to absolute

Read `notes.md`. It states "Today is 2026-09-08." and lists bullets with a
relative date phrase (tomorrow, yesterday, "in N days", "next week" = +7
days). Write `output.md`: same bullets, in the same order, each rewritten
to append the absolute date in parentheses as `(YYYY-MM-DD)` right after the
phrase, e.g. `- meeting tomorrow (2026-09-09)`. Keep the original wording.

# Task: word count CLI

Write `run.sh` (any language it invokes) that, run with no arguments in
this directory, counts words (whitespace-separated tokens) in every `.txt`
file here and prints one JSON object to stdout mapping each filename to its
word count, e.g. `{"a.txt": 9, "b.txt": 5}`. Exactly one JSON object, no
other stdout output.
